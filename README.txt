Как выложить (все файлы в КОРЕНЬ репозитория, без подпапок):
1. GitHub -> репозиторий -> Add file -> Upload files -> перетащить ВСЕ файлы из этой папки (не саму папку) -> Commit.
2. Settings -> Pages -> Branch: main, папка / (root) -> Save.
3. Через минуту открыть https://ИМЯ.github.io/РЕПОЗИТОРИЙ/ в Chrome (Android) или Safari (iPhone).
Проверка: к адресу допишите manifest.webmanifest - должен открыться текст, а не 404.
