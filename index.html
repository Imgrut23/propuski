Условные обозначения

Б болезнь
УП уважительная причина по заявлению (только для факультета права)
ПН причина неизвестна (считается пропуском)
Н меня не будет (не идёт в общие часы)
СБ спортивные сборы (соревнования)
ОМ общественные мероприятия
Ц ЦКВР (Центр культурно-воспитательной работы)
ПР присутствовал, но не принимал участия по состоянию здоровья (только физкультура; пропуском не считается)
